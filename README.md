# Cinescope 🎬

Cinescope is an IMDb-inspired movie review platform that allows users to explore and review movies. The application features user authentication, personalized profiles, and detailed movie information.

## Features ✨
- 🔐 **User Authentication:** Secure login/signup using Firebase Authentication.
- 🎥 **Movie Exploration:** Browse a vast collection of movies with details.
- 📝 **Review System:** Users can submit and read reviews for movies.
- 👤 **User Profiles:** Each user has a profile displaying their reviews.
- 🔍 **Search Functionality:** Find movies easily.

## Tech Stack 🛠️
- **Frontend:** React.js, Material UI
- **Backend:** Firebase (Authentication & Firestore for database)
- **Hosting:** Netlify

## Installation & Setup ⚙️

1. Clone the repository:
   ```sh
   git clone https://github.com/saiteja218/CineScope
   cd cinescope
   ```
2. Install dependencies:
   ```sh
   npm install
   ```
3. Start the development server:
   ```sh
   npm run dev
   ```
